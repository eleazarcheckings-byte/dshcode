<a id="summary"></a>
## 概述

此 Client 插件在主应用右上角提供 SaturnBot 启动按钮，在名为 `saturnbot` 的窗口中打开同源 `/?saturnbot=1` 路由。再次点击会聚焦已打开的界面而不重新加载，保留未发送草稿；关闭后下次点击可重新打开。桌面端的原生最小化会隐藏管理界面并返回主应用；同一启动按钮通过职责有限的桌面桥接恢复保留的窗口。浏览器客户端使用普通窗口聚焦。[桌面包](../../../apps/desktop/README.zh.md) 负责原生窗口许可和最小化行为。独立界面将被覆盖的主应用设为 inert，并设置自己的产品窗口标题。

<a id="agent-workspace"></a>
## 智能体工作区

三栏消息界面包含参谋长和四位专家、按角色划分的对话，以及执行检查器。各角色保留独立本地草稿。Enter 发送，Shift+Enter 换行，并尊重输入法组合输入。命令失败时保留草稿并显示错误。是否能启动新请求由运行时执行租约决定。

检查器展示真实分支、工具载荷、错误、暂存路径和版本、审批状态、模型、工作区及计划。画布仅沿运行中或规划中的分支显示移动信号。执行状态旁的暂停/恢复可视化动画按钮独立控制动画，不影响智能体工作或调度。暂停保留信号位置，分支拓扑和状态继续更新；恢复时从该位置继续，并始终优先遵循系统的减少动态效果设置。该选择只保留在当前打开的管理界面中，隐藏检查器后仍会保留。DOM 中始终保留状态文字；装饰动画限制为每秒 30 帧和 DPR 2，在页面隐藏、离开视口或用户偏好减少动态效果时停止，并清理观察器与帧回调。SVG 提供静态后备显示。

运行视图保留已记录摘要和状态。审批在允许或拒绝前展示准确操作输入及暂存版本。记忆视图读取专用记忆、工单和 webhook API，并渲染持久 Markdown 简报。保留 Host 的排序：消息按时间顺序排列，报告、提醒、审批和运行按最新优先排列。连接行区分已配置与未配置，不声称未经验证的健康状态。

<a id="state-and-commands"></a>
## 状态与命令

可直接从源码测试的挂载入口管理生成的 SaturnBot Remote 贡献。私有且不依赖 React 的 `SaturnBotController` 通过插槽注入的 `hooks.bot` 发布 `createSnapshotStore`，由渲染器生成 `useBot`。组件只接收普通数据和回调，不接收 Cordis Context。

控制器串行处理变更与刷新，共享重叠刷新请求，忽略销毁后的结果及较旧快照，并避免后续轨迹读取失败将已接纳命令变为失败。即使窗口最初处于隐藏状态，也会加载一次初始快照；后续自动刷新等待窗口可见。初始快照最多通过五页、每页 200 条记录加载最近 1,000 条日志；界面明确标注该限制。可见且运行中或待审批的工作每两秒刷新。空闲实例在获得焦点、用户请求或下次计划运行边界时刷新。主窗口启动按钮不启动轮询。

设置提交明确的配置草稿：工作区、业务目标、模型及提供方 ID、计划、操作策略、按角色划分的指令与准确工具允许列表、命令限制、验证命令数组以及集成环境变量引用。Host 负责验证、工具权限、调度、持久化和执行。首次运行在必需配置完成前会打开配置界面。

<a id="guided-setup-connect-forms-and-the-status-strip"></a>
## 引导设置、连接表单与状态提示条

只要运行时报告 `needs-setup`，设置页就会打开五步引导设置（目标、工作区、模型、连接、计划），并从 Host 尚未填写的第一个字段继续；每次「继续」只保存该步骤，因此中途关闭也不会丢失进度。状态提示条准确说明仍阻止运行的具体事项——某个必填字段为空，或 Host 未能解析的凭据——或明确说明 SaturnBot 现在即可运行。两个界面都可互相跳转回高级配置。工作区步骤的「浏览…」按钮会打开 Host 的原生目录选择器（通过注入的 `uiWorkspace` 服务）；选择器被取消或不可用时，自由输入的路径字段保持不变。

「连接」是根据 Host 的集成目录生成的字段级表单，每个集成一份：对于运行时固定集成记录所接纳的非密钥字段（仓库标识、端点 URL）是普通文本输入；目录中命名的其他字段键（运行时尚不支持来回处理）显示为禁用状态的说明文字；密钥字段只展示所需的确切环境变量名，附带复制操作和应粘贴到的文件位置——绝不提供可输入密钥值的输入框。生成表单下方保留「高级 JSON」折叠面板，可直接访问原始集成对象；当该草稿无法解析时，生成表单会自行禁用并显示「请先修复」提示，而不会在下一次字段编辑时把草稿折叠为空对象。

本包在 Host 运行时包（`@saturnai/dsh-saturnbot`）落地 `firstRun`/`integrationCatalog` 快照字段之前，就针对这两个字段编码——通过 `contracts.ts` 中的本地放宽类型 `SaturnBotSnapshot`，将两者都保持为可选。当某个快照缺失这些字段时，本包中的每个读取点都会回退到引导设置之前的行为——状态提示条回退为四项基于配置的检查，连接表单显示其空状态——因此两个包可以按任意顺序落地。

<a id="model-experience"></a>
## 模型体验

### 操作员消息发送

#### 模型看到的内容

本包自身不创建模型会话或提示词。其消息命令（`controller.ts` 中的 `message(role, content)`）只将选定的 `BotRole` 与操作员的原始文本原样转发给 SaturnBot Host 的 `message` 方法（[contracts.ts](src/client/contracts.ts) 中的 `SaturnBotRemote`）；Host 自身的 `botModelPrompt`（见 [packages/saturn/saturnbot](../../saturn/saturnbot/README.zh.md#model-experience)）会把这段内容组装进下一次领域代理请求。本包不添加任何历史记录、格式化或自造上下文。

#### Token 影响

在本层没有影响。转发的 `content` 字符串是唯一负载；其余每个模型上下文字段（目标、工作区、角色说明、观察数据、此前轮次）都由 Host 从持久状态组装，而非由本包组装。

#### KV 缓存影响

没有影响。本包每次发送只发出一次 RPC 调用，不持有任何缓存前缀；任何缓存复用都取决于 Host 自身的按次组装方式，具体见其 README。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 此界面管理一个已配置工作区实例，不实现多租户计费或账户隔离。
- 近期工具日志限制为 1,000 条，Host 提供有界运行、消息和报告历史。此处尚未提供完整日志导出和更早消息分页。
- 连接配置表示配置存在，不代表健康探测。消息草稿只保留在当前窗口中，关闭窗口后不会持久保留。桌面弹出窗口许可和原生窗口行为由桌面包管理。
- 引导设置的模型步骤提供一份静态、无需密钥的常见提供方标识符作为快捷选项；这并非对主机已配置提供方目录（`@saturnai/dsh-model-router`）的实时查询，因此该字段保持自由输入，不会阻挡未列出的提供方。
- 当快照的 `firstRun` 未携带 `envPath` 时，连接表单中「.env 路径」提示会回退为通用文案——SPEC 文档化的快照约定并未命名此字段；在 Host 侧补上它是后续的小改动。
- 「浏览…」按钮仅存在于引导设置的工作区步骤；高级配置页面自身的工作区字段仍只提供工作区列表和自由输入路径，没有选择器按钮。

<a id="dev-note"></a>
### 开发备注

运行 `pnpm exec vitest run packages/client/ui-saturnbot/tests --maxWorkers=2` 检查消息、审批、记录、控制器排序、窗口生命周期、画布、引导设置、连接表单及状态提示条行为。构建生成的 Host Remote 后运行 `pnpm exec tsc -p packages/client/ui-saturnbot --noEmit`。词典管理英文和简体中文产品文案，UI 国际化检查未报告本包中的硬编码文案。构建及原生、浏览器冒烟验证使用完整应用。
