# Agent Note: Release-hygiene sweep for 1.2.1 — the media tools, the countersign event, and doc-quick

Status: implemented

English | [中文](2026-09-15-release-hygiene-1-2-1.zh.md)

## Problem

The 1.2.1 release carried five media tools (`@saturnai/dsh-tool-media`) and the Agent Teams `merge_teammate` tool without their generated catalogs catching up: `gen-tool-catalog.spec.ts`'s harvested-name expectation still listed 66 tools against the 72 the boot actually produces, `gen-config-catalog.ts` refused to write over ten undocumented config fields across `tool-media`'s three providers, and `gen-cordis-catalog.ts` refused over eight missing `@returns` contracts in `model-router` and `tool-media`. Once those two generators ran clean, a second, deeper layer of `gen-cordis-catalog.ts`'s signature type-link coverage check — masked until then by the first thrown error — surfaced 24 more violations: seven Saturn packages' service methods referenced return/param types the generator's `linkedTypePages`/`typeLinkExemptions` registry had never classified. `scripts/run-gates.ts doc-quick` was failing 5 of 15 checks for reasons spanning a hard-wrapped Agent Note, two package READMEs missing canonical Model Experience sections, a dead tool-catalog anchor, a very large translation-pairing backlog (`docs/config-catalog.md` and `docs/persistence-catalog.md` had drifted far ahead of their Chinese counterparts across several unrelated commits, not just this release), and a `claims`/`model-router`/`tool-media`/`skill-premium-output` README.zh.md quartet still on inconsistent Chinese section headings (摘要/概览/开发者说明/开发说明 instead of the standard 概述/开发备注).

## Decision

Updated the expected-tool-name list and JSDoc contracts in the owning files, never by weakening a check: `gen-tool-catalog.spec.ts` now lists all 72 harvested names sorted; ten `tool-media` provider config fields (`gemini.ts`, `openai.ts`, `higgsfield.ts`) and the nine loader-facing `index.ts` fields around them got one accurate JSDoc line each describing real semantics and defaults; `model-router`'s `externalHarnessesEnabled`/`externalHarnessMounted` and `tool-media`'s `withAgent`/`generate`/`status` got complete `@param`/`@returns` contracts stating behavior, failure, and ownership. For the type-link layer, `scripts/gen-cordis-catalog.ts`'s `TYPE_LINK_EXEMPTIONS` gained entries for `model-router`'s `ModelTier`/`TierRoute`/`ExternalHarness`, `tool-media`'s `BoundMediaService`/`MediaExecContext`/`MediaGenerateRequest`/`MediaJob`, and — since they were unclaimed, uncontended, and additive-only — `agent-team`'s `MergeTeammateRequest`/`MergeTeammateResult`, `claims`'s `ClaimCheckRequest`/`ClaimPathConflict`, and `design-brain`'s `DesignBrainStatus`. `remote-access`'s four unclassified types (`RemoteStatus`, `RemoteMode`, `RemotePairingPayload`, `RemoteEventInput`) were left unclassified: that package was under active concurrent edit for this same release and is out of this cell's assigned scope, so `gen-cordis-catalog.ts`/`gen-cordis-api.ts` remain red for that one package until its owning cell registers its own types.

`docs/config-catalog.md` and `docs/persistence-catalog.md` had each accumulated a full generation of undocumented drift beyond this release's own additions — new `@saturnai/dsh-design-brain`, `dsh-model-router`, `dsh-remote-access`, `dsh-review`, `dsh-saturnbot`, and `dsh-skill-premium-output` config sections, an `agent-team.worktreeRoot` field, an `mcp-client.connectTimeoutMs` field, and a `saturnbot/*` persistence section — none of it mirrored into the `.zh.md` sides. All of it was translated and mirrored in this pass (JSON/TS code fences copied byte-identical per the pairing contract, including matching three fences' CRLF line endings the generator inherited verbatim from Windows-authored source files); `docs/tool-catalog.zh.md` gained the parallel `merge_teammate` tool and the new `@saturnai/dsh-tool-media` section. Every other out-of-sync pair the gate listed (`README.md`, the eight `docs/cordis-tutorial/*` pages, `packages/boot/app-boot`, `packages/core/system-prompt`, `packages/sandbox/sandbox-policy`, `packages/skill/skill-badge`, `packages/skill/skill-premium-output`) turned out to be a stale consistency record over an already-symmetric prior rebrand edit (verified line-for-line against the commit that touched both sides identically) and was re-recorded with `--write`, not re-translated. `packages/client/ui-brand-official/README.zh.md` and `packages/experimental/webworker-runtime/README.zh.md` had a genuine untranslated sentence each (the fish-to-Saturn-mark rebrand; the `global` alias fix) and got real translation passes. `claims`, `model-router`, `tool-media`, and `skill-premium-output`'s README.zh.md files were normalized onto the standard 概述/开发备注 skeleton headings the `doc-standard.spec.ts` gate requires; `model-router`'s README.zh.md had left every top-level heading in English entirely and is now fully translated. `apps/mobile/ios/App/CapApp-SPM/README.md` — a file Capacitor's own tooling regenerates on every native sync — was added to `scripts/translation-pairing.manifest.json`'s `excluded` list and documented in `docs/i18n/README.md`'s Excluded section, rather than given a translation that the next `pod install` would immediately stale; the exclusion is scoped to that one file, not `apps/mobile/**`, because the top-level `apps/mobile/README.md` is a real, actively maintained bilingual page.

The five hard-wrapped Agent Notes and one package README the gate found beyond the one named in the original brief (`2026-09-15-saturnai-tools-front`, `2026-09-15-model-router-mars-r2-fixes`, `2026-09-15-tool-media-mars-fix-round`, `packages/client/ui-primitives/README`) were joined to one physical line per paragraph the same way, since they were already-committed, unrelated-to-any-concurrent-cell content and fixing them cost nothing extra once the join tooling existed for the required file. `2026-09-15-peak-lamp-top-rail.*` and `2026-09-15-apps-mobile-replay-endpoint.*` were left wrapped: both are today's in-flight work product of the `ui-conversation` and `apps/mobile` cells, which this cell was explicitly told never to touch.

## Alternatives considered

**Also classify `remote-access`'s four types to get `gen-cordis-catalog`/`gen-cordis-api` fully green.** Rejected: `packages/saturn/remote-access/**` was explicitly off-limits for this cell because another cell was concurrently editing it in the same shared working tree; guessing at that package's intended documentation ownership risks contradicting whatever entry its own cell adds to the same shared `TYPE_LINK_EXEMPTIONS` map.

**Re-translate the stale `docs/config-catalog.md`/`docs/persistence-catalog.md` drift from scratch.** Rejected: most of the backlog was symmetric, already-correct rebrand or line-number churn; the pairing contract's own minimal-patch principle (`docs/i18n/README.md`) calls for patching the counterpart against the diff, not re-translating whole files.

## Consequences

`gen-tool-catalog.ts`, `gen-config-catalog.ts`, `gen-client-catalog.ts`, and `gen-persistence-catalog.ts` all write clean; `gen-cordis-catalog.ts`/`gen-cordis-api.ts` still refuse solely on `remote-access`'s four unclassified types, owned by that package's own cell. `scripts/run-gates.ts doc-quick` reports 13 of 15 passing; the two remaining failures are `packages/client/ui-sidebar/README.zh.md` (translation pairing) and `2026-09-15-peak-lamp-top-rail.*` / `2026-09-15-apps-mobile-replay-endpoint.*` (markdown wrap) — every one inside a path this cell was told never to touch, and each actively being written by its owning cell this same session. `node_modules/.bin/vitest run` over `packages/saturn/tool-media`, `packages/saturn/model-router`, and `packages/core/tools/tests/gen-tool-catalog.spec.ts` passes (95 tests); `tsc --noEmit` is clean for both `model-router` and `tool-media`. Working in the same shared git working tree as sibling cells reproduced the hazard the prior `2026-09-15-saturn-hygiene-docs-sweep` note recorded: several of this cell's source edits (the JSDoc contracts in `tool-media`'s and `model-router`'s `src/`) were swept into unrelated sibling commits before this cell reached its own commit step, rather than landing in either of the two commits this note accompanies. The content is correct and already on `HEAD` either way; only the audit trail is impure.
