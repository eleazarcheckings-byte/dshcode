# Agent Note: SaturnBot 首次快照独立于窗口可见性加载

Status: implemented

[English](2026-09-15-saturnbot-initial-snapshot.md) | 中文

## Problem

安装后的 Electron 弹窗已显示静态角色列表，但首次 SaturnBot 请求在导航后约 199 秒才发出。普通会话请求在 512 毫秒时已开始。获得焦点激活界面后，快照与事件接口分别在约 8 毫秒和 12 毫秒内返回 HTTP 200。因暂时隐藏状态跳过初始化，会让可用内容依赖后续焦点事件。

## Decision

独立界面挂载时，SaturnBot 控制器请求一次初始快照，包括 `document.hidden` 为 true 的情况。窗口可见性控制后续自动刷新及其定时器。主窗口启动按钮不启动控制器。

## Alternatives considered

**将初始请求延迟到窗口可见时。** 暂时隐藏状态可能使管理界面一直等待后续焦点事件，才能显示可用内容。

## Consequences

隐藏的管理界面执行一次有界初始读取。这消除了对后续焦点事件的依赖，同时让后续后台轮询在窗口可见之前保持安静。

## 验证

控制器回归测试在隐藏状态启动，不主动调用刷新即可观察到初始快照；隐藏时没有轮询定时器，恢复可见后刷新及轮询正常。该测试在按可见性限制初始化的版本上失败。现有顺序、变更、销毁和可见轮询测试仍然适用。完整浏览器回归在挂载时将文档设为隐藏，并要求真实 Remote 投影替换加载状态。

## 模型体验

此变更只读取现有状态，不创建模型请求、不修改提示词，也不引入虚构执行事件。
