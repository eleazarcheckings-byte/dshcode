# Agent Note: 上下文菜单事件保留在 portal 卡片内

Status: implemented

[English](2026-09-15-context-menu-event-containment.md) | 中文

## Problem

即使 DOM 卡片位于 `document.body` 下，React 事件仍会跨 portal 沿组件祖先传播。会话行同时拥有导航和上下文菜单组件。如果不限制传播，同一次重命名点击会调用重命名回调和行导航回调。

## Decision

共享 `ContextMenu` 卡片阻止点击和上下文菜单事件向外传播。选择菜单行只调用菜单回调，不会同时激活在 React 子树中拥有该 portal 的控件。在卡片上右击会阻止浏览器菜单，也不会重新打开来源控件的菜单。

## Alternatives considered

**在工作区行中添加针对 portal 的目标检查。** 这会将事件隔离分散到每个可点击来源。共享原语让所有来源获得相同的事件隔离行为。

## Consequences

工作区行无需添加针对 portal 的目标检查。菜单选择与来源控件的普通激活保持为独立操作，而卡片内部的右击事件保留在菜单内。

## 验证

原语回归测试在可点击控件内渲染 portal 卡片，选择重命名后断言只调用一次选择回调且未激活父控件。还验证右击隔离以及原控件仍能正常激活。现有工作区行回归保留重命名、分叉和归档时不导航的断言。组合后的重命名测试通过真实工作区插件与渲染器验证成功重命名和错误保留。

工作区 fixture 提供插件打开文件夹集成已要求的 `remote.session` 命名空间，apply 测试验证该操作调用 `openWorkspacePath`。深色主题和 Saturn 品牌期望与产品默认值一致，同时保留显式偏好变更、无操作更新及构建版本后缀测试。不通过削弱运行时行为来满足过时期望。

## 模型体验

此修复只更改指针事件路由，不创建或修改模型可见内容或持久会话事件。
