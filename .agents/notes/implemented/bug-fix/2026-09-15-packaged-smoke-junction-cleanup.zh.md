# Agent Note: 删除打包冒烟检查的配置目录联接而不遍历目标

Status: implemented

[English](2026-09-15-packaged-smoke-junction-cleanup.md) | 中文

## 问题

打包桌面可以成功渲染，但启动冒烟检查在递归删除私有配置目录时因 Windows `EPERM` 而失败。该配置包含指向冒烟目录之外的包目录联接。继承的子进程输出还会暴露一次性预览 URL 令牌。

## 决策

[启动助手](../../../../apps/desktop/scripts/smoke-packaged-startup.mjs) 验证临时根目录，拒绝链接形式的根目录，解除后代链接而不访问其目标，再通过有限重试删除剩余真实目录树。它捕获有大小限制的子进程输出，并在打印之前去除 URL 凭据、查询参数和片段。清单恢复、测试入口删除和临时目录清理都会尝试执行；这些步骤的失败与启动失败一起保留。

## 考虑过的替代方案

**原样重试递归删除。** 旧重试循环在实际配置目录联接树上仍会失败；等待不能修复链接处理缺陷。

**成功渲染后忽略清理失败。** 这会遗留临时凭据和浏览器状态，并错误报告发布检查结果。

## 影响

清理增加了一次链接扫描，但不会遍历包目标或修改已安装应用。[专项测试](../../../../apps/desktop/tests/packaged-startup-smoke.spec.ts) 验证外部目录联接目标保持完整、拒绝不安全根目录，以及令牌脱敏后仍保留有用诊断。此前清理失败的 Windows 临时目录可由修正后的助手删除，同时打包清单保持不变。
