# Agent Note: Host 管理的可选设计工具

Status: implemented

[English](2026-09-15-host-owned-design-brain.md) | 中文

## Problem

引导中的 HTTP 探测可以报告服务已应答，却没有给智能体任何工具。仅在开发者电脑上配置的 profile 也不能证明新用户可用。用户需要一个持久连接，其状态反映智能体实际使用的适配器和工具注册表。

## Decision

提供带生成 Remote API 的可选 Host 连接器。First Light 和常驻 Models 设置卡片共享其状态与命令。现有 MCP 适配器拥有传输、schema 和执行；连接器只拥有保存的选择和托管子实例生命周期。同一作用域的配置条目保持独立所有权，复用时不改动它。其他智能体作用域不阻止全局连接。

完整连接要求活跃的监督器实例以及已注册的 compose 和 review 工具。工具列表不完整、条目停用、超时或刷新失败都明确呈现。仅在已连接工具对模型所在作用域可见时，模型才收到相关使用指令，并明确评审依赖调用方提供的证据。内置高品质指南在没有外部服务时仍然有用。

MCP 监督器支持覆盖握手、初始化通知和首次工具发现的可选期限。到期时会先关闭实际传输，再等待清理。外层超时后释放 Fiber 不能提供此保证，因为异步插件启动可能将释放处理推迟到启动结束。

## Alternatives considered

**浏览器探测加已保存的记忆偏好。** 这能证明端点可达，却不能挂载工具或保留工具生命周期。

**自动写入另一个配置条目。** 这会带来命名空间冲突风险，并改动部署拥有的配置。连接器选择复用已有条目，通过设置存储托管启用选择。

**将每个已注册包装视为已连接。** MCP 在重连期间保留包装；状态结合监督器健康状态与实际必需目录。

## Consequences

新配置不发起连接请求。连接和断开会立即持久化并生效；直接编辑设置在重启时生效。引导可跳过可选集成，之后仍能访问常驻设置控件。端点请求头保持 Host 所有权，连接状态省略 URL 凭据和查询。连接时不上传项目文件或对话历史；后续工具调用携带智能体提供的参数。

其他 MCP 使用方可选择设置传输期限，现有默认值保持不变。测试使用真实 Loader、文件设置和生产 MCP 传输连接本地协议服务器，覆盖三个启动停滞阶段、重试、释放、配置复用、工具调用和持久启用选择。UI 测试覆盖连接操作、失败状态、本地化和所有权。

既有的打包产出质量和 MCP 生命周期记录仍各自有效；此决策增加连接所有权，不替代工作流程或传输语义。
