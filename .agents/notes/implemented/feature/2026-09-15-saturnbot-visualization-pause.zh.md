# Agent Note: SaturnBot 可视化动画独立于执行暂停

Status: implemented

[English](2026-09-15-saturnbot-visualization-pause.md) | 中文

## 问题

在操作员阅读消息和审批时，SaturnBot 执行图可能在整个长时间运行期间持续移动。独立管理界面没有主应用的环境动画控制。隐藏检查器会失去有用上下文，而暂停计划并不能表达停止视觉动画的意图。

## 决策

在执行状态旁提供原生暂停/恢复可视化动画按钮。本地化名称和提示区分视觉动画与智能体工作。管理界面的本地状态在切换检查器和原生窗口最小化后保留；关闭或重新加载管理界面会重置该状态。

画布将此偏好纳入动画运行条件。暂停会取消帧回调并保留累计活动时间。分支变化仍会重绘当前拓扑和状态。恢复使用保留的动画位置，不补算暂停期间的实际时间。系统的减少动态效果设置、页面隐藏或离开视口时的暂停，以及既有帧率和像素密度限制仍然优先适用。

此变更为[智能体消息界面](2026-09-14-saturnbot-agent-messenger.zh.md)添加视图控制；传输、轮询和执行职责保持不变。

## 考虑过的替代方案

**使用暂停计划。** 该操作改变后续执行，不控制当前执行图。操作员必须能够在工作继续时查看静态可视化结果。

**依赖系统减少动态效果或隐藏检查器。** 两者已经可用，但局部视图选择无需改变系统偏好或失去执行上下文。

**导入会话插件的环境动画控制。** 功能插件不共享运行时实现，而且该控制负责独立的装饰星空。此局部操作不需要新的跨插件服务或持久化配置。

## 影响

操作员可以保留实时上下文而不持续显示动态效果。偏好仅保留在当前管理界面中，不引入 Host 命令或模型输入，也不在窗口关闭后持久保存。隐藏检查器会保留偏好但重新挂载画布；动画位置保留适用于画布持续挂载期间的暂停和恢复。

## 验证

画布测试覆盖帧回调取消、暂停期间的实时拓扑重绘、长时间暂停后保留动画位置，以及减少动态效果设置的优先级。管理界面测试覆盖可访问操作及其快照、暂停后的当前执行状态、切换检查器后保留偏好，以及不发送调度或执行命令。
