# Agent Note: Packaged output quality for Saturn AI agents

Status: implemented

[English](2026-09-15-packaged-output-quality.md) | 中文

## 问题

精致的 harness 界面并不会自动为 agent 提供产出精致交付物所需的工作流。用户本地指令和引导流程中的端点探测无法为所有部署或选定 agent 预设建立共享设计过程。视觉质量也不能从构建成功或模型自身的完成声明推断。

在一次响应中生成整个交付物可能在任何文件写入执行前耗尽响应上限。如果响应在稍后被截断，其中完整的写入提案仍会被现有工具调用保护机制丢弃，因此仅有详细规划并不会留下可用交付物。

## 决策

[skill-premium-output](../../../../packages/skill/skill-premium-output/README.zh.md) 通过 `systemPrompt.section` 贡献简短共享策略，并通过现有技能注册表贡献不可变指南。挂载由 `dsh-base` 组合拥有，因此其普通 profile 共享这些指导。插件不修改循环、不调整模型路由，也不授予工具。现有请求头记录策略，现有技能工具记录加载的指令。完整 persona 保留其精确提示词语义。

三个指南分别覆盖网站、有目的的动效与一般交付物。内置助手提供具体的渲染与检查技术，无需安装到用户拥有的目录，也不会自动启动。项目和用户技能通过常规技能优先级覆盖内置名称；任务范围和品牌遵循用户指令。

策略和指南要求实质性工作先保存可用的初始版本，再通过完整增量和相关检查逐步完善。这样，即使后续完善被中断，已执行的结果仍然可用。定向修改保留现有行为，初始版本仍只是完成完整任务的中间成果。指导不会强制预留 token、改变所选推理强度或执行被截断的工具调用。

## 考虑过的替代方案

**依赖私有全局指令文件或外部 Design brain 探测。** 两者都不能建立部署范围的指令，也不能保证 agent 可以访问被探测的工具。内置提供器无需网络即可使用。

**将所有指南插入每次请求。** 这会给小任务增加无关上下文。共享策略保持简短，完整指南通过现有按需披露机制加载。

**强制使用更强模型或额外评审轮次。** 这会改变用户成本与延迟，却不能证明视觉质量。用户选择的模型与执行预算保持权威；agent 在评审有助于实际任务时使用它。

**提高响应上限，或执行被截断响应中的完整调用。** 更大的上限并不会要求模型完成一次写入。执行一组预期修改中的部分内容可能导致文件不一致。小而完整的步骤可保留有用成果，无需削弱截断保护。

**将截图或构建通过视为自动质量评分。** 此类检查只能证明可观察事实，不能证明审美判断或完整交互覆盖。指导区分渲染、检查、行为验证和如实报告。

## 影响

普通 agent 在不同模型路由下获得一致的产出要求和可复用技术。专用 Loader 夹具在 native 与 PTC 模式中使用脚本化模型、真实技能和文件执行及持久化会话日志。它验证已保存的交付物在后续完善响应被截断后仍保持完整，且该响应中完整和不完整的工具提案均不会执行。单元测试覆盖释放、配置、覆盖优先级、隐藏工具、资源路径与完整 persona。这些测试证明工作流已传递且已完成写入得到保留，不证明模型遵循或生成设计的质量。

明确的 minimal profile 和完整自定义 persona 可省略该策略。浏览器检查仍依赖可用工具；缺少依赖必须报告，不能转换成通过结果。内置指南和无密钥测试无需提供方凭据。
