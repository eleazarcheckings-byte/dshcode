# Agent Note: Saturn 快速切换

Status: implemented

[English](2026-09-14-saturn-quick-switch.md) | 中文

## Problem

在对话和工作区之间移动需要先找到对应的侧边栏行。侧边栏收起或对话列表很长时，这会拖慢用户编写内容或协调工作时的导航。

## Decision

工作区 UI 基于当前会话和工作区快照提供 Ctrl/Cmd+K 面板。它在本地匹配元数据，优先显示标题匹配项，同分时保留最近更新时间或工作区顺序，并排除已归档和空白对话。渲染列表最多包含 30 个目的地；新建对话操作匹配时会额外显示。选择项目后交由现有的打开或开始会话操作处理。

面板将焦点保留在一个 combobox 中，向辅助技术暴露当前选项，支持方向键选择和 Enter，并在关闭时将焦点返回调用控件。全局快捷键不会打断另一个模态工作流，并随工作区浏览器卸载而移除。

## Alternatives considered

复用侧边栏内容搜索会给导航动作增加远程搜索延迟。由模型生成导航会为了浏览器状态中已有的目的地消耗一次模型请求。将会话数据复制到新 store 会要求同步第二份数据。面板直接从框架现有快照派生结果。

## Consequences

搜索不需要远程请求、模型调用或仓库扫描。它覆盖已加载的元数据，而非对话内容；后者仍由侧边栏独立的内容搜索承担。结果上限限制渲染和键盘遍历的规模，打开目的地则使用正常会话导航。
