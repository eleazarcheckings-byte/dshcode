# Agent Note: 土星会话环境动画跟随书写状态

Status: implemented

[English](2026-09-14-saturn-conversation-ambience.md) | 中文

## Problem

应用需要清晰可识别的视觉身份和实用的对话起点，同时不能分散编辑器的注意力。书写时持续播放或暗示智能体活动的动画会降低界面的可读性和可理解性。

## Decision

会话包通过布局拥有的 `shell.background` 插槽提供一个覆盖整个窗口的 canvas。画布位于各应用栏后方，在会话及 Hero 状态切换时保持挂载。Hero 为常驻 composer 上方的土星提供布局锚点；移除锚点后，共享星空仍然保留。独立 SaturnBot 窗口不显示此背景，使用自己的执行画布。

空闲时光照和环的倾角缓慢变化。空 composer 获得焦点时，动画以 65% 的速度运行，因此自动聚焦不会隐藏环境动画。文字或图片草稿非空，或正在编辑其他文本字段时，图形保持静止。有效动画时间跨偏好和焦点变化保留，暂停时保持当前角度和反射光位置。右下角的动态效果控制与星空共享一个按应用实例创建的可观察偏好，并将其保存在浏览器存储中。系统减少动态效果、文档可见性和视口相交状态也共同控制动画时钟。绘制采用四百万后备位图像素预算，显示密度上限为 2，速率不超过每秒 30 帧。卸载时移除所有监听器、观察器和待执行帧。缺少 canvas 后端或有效显示尺寸时保留静态 SVG。

单色星空将星点和流星路线分布在应用的整个宽度和高度内。星座位于上部和下部；窄区域降低密度，同时保留下部星座。中性漫射光照和星点亮度缓慢变化，在短流星的间歇期间维持背景氛围，星点本身不移动。同一时刻最多出现一颗流星，尾迹规模有固定上限。所有效果共用现有动画时钟，因此暂停、草稿、减少动态效果和可见性规则作用于整个场景。鼠标靠近时，星座连线的亮度平滑增强；不产生视差，也不捕获指针。简短的入场淡入遵循同一动态效果偏好。

品牌 slot、工作区选择器、预设选择器和 composer 保持原有归属。本地化起始操作只填入可用的空草稿，绝不提交。书写时保留操作区空间，避免 composer 位移。价格指示器使用常亮指示灯，移除随机粒子。

土星皮肤提供共享的表面、边框、文字、强调色和动态效果语义 token。组件维护各自的动画生命周期，并以上游 alias 作为回退。

## Alternatives considered

**在整个应用中持续播放粒子。** 这会让无关活动获得同样的视觉重点，与用户工作没有明确关联，并在阅读或书写时增加绘制成本。

**仅显示静态标志。** 成本低，但无法提供用户要求的独特 canvas 构图。SVG 仍用于能力不足时的回退。

**独立的 Hero 编辑器。** 第一次会话切换时会重新挂载草稿，可能丢失选区或撤销历史。常驻 composer 保持原位。

## Consequences

应用在会话和 Hero 内容变化时保持视觉身份，常驻 composer 和草稿起点保留原有行为。单个画布避免重复动画时钟，并限制全窗口渲染成本。动画不表示运行进度或成功状态。浏览器存储被禁用时，动态效果偏好只在当前应用实例中生效；开关仍然可用。

## Verification

定向组件测试覆盖控制器共享偏好、存储访问被拒绝、草稿和其他编辑器聚焦时静止、空 composer 聚焦时的动画、无会话渲染、排除 SaturnBot，以及焦点监听器清理。注册测试验证单个背景条目和共享偏好源。画布测试覆盖土星锚点改变时保留同一星空、全窗口后备位图像素及显示密度限制、帧预算、动态减少效果偏好、帧连续性、隐藏和离开视口时暂停、零尺寸和缺失后端时的回退绘制及清理。星空测试覆盖流星路线遍及窗口横向和纵向的全部三等分区域、宽屏中的等比例行程、流星之间的间隔、指针揭示时星点位置不变，以及窄区域降低密度。SVG 星座路径和一个已绘制流星的位置具有所属包内快照。Hero 和 composer 测试验证土星锚点、本地化起始操作可用性，以及会话切换前后保留同一个编辑器。调色板测试覆盖色阶顺序和文字对比度。

[装配后的浏览器测试](../../../../apps/web/tests/ambient-canvas.e2e.ts)验证桌面和窄窗口中画布覆盖整个布局、连接 Workspace 时保留同一个画布、暂停期间收放侧栏时土星仍然对齐、书写或减少动态效果时像素保持不变，以及设置面板位于主内容上方且可正常操作。
